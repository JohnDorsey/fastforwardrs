These project files and the files beside them are the gate of phase 9 (text objects become generators: `docs/engine-phase-9-design.md`, T9). Nothing in this folder is to be edited by hand.

* `*.json` are project files **of format 17, as the program wrote them before phase 9**, with `tests/text_fixtures_writer.rs` (a test that was marked to be ignored; it named the properties of a text that phase 9 took away, so it was deleted with them in 9.4: `git show 8e01c0a:tests/text_fixtures_writer.rs` has it, and it was written for the program as it was then). They are plain text, so they can be read:
  `plain` (two texts on a track), `animated` (the words, font, size, colour, place and turning of a text change), `with_effects` (effects of the program on a text, one with a value that changes, and an effect on its track), `racks_and_crates` (keyframes in racks of
  the drawer, one rack taken out onto a keyframe crate on another track, two others in the drawer), `cut_in_two` (a text cut in two, with keyframes across the cut), `in_groups` (two texts in a tag, a clip group and a track group, each with an effect).
* `*.expected.txt` are what `tests/text_objects_as_they_are.rs` says of them: for the frames it looks at, the text object that each text clip is, what the text drawer was asked to draw, and every layer of the frame with its corners and every effect with its numbers.
  They were written by the program before phase 9 (`WRITE_THE_TEXT_EXPECTATIONS=1 cargo test --test text_objects_as_they_are`) and **must come out the same after the migration to format 18**. If they do not, the migration or what the describer reads is wrong; the files are not to be rewritten to make a test pass.
